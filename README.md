# java-lotto-precourse

## 구현 기능 목록

- [X] 구입 금액 입력 및 유효성 검사
    - 금액은 1,000원 단위의 숫자만 허용
    - 1,000원으로 나누어떨어지지 않으면 예외 발생

- [ ] 로또 발행
    - 구입 금액에 따라 로또 개수 계산 (1장당 1,000원)
    - 1~45 사이의 중복되지 않은 6개 번호 자동 생성
    - 생성된 번호는 오름차순 정렬 후 출력

- [ ] 당첨 번호 입력 및 유효성 검사
    - 쉼표 기준으로 구분된 6개 숫자 입력
    - 1~45 범위의 중복되지 않은 숫자만 허용

- [ ] 보너스 번호 입력 및 유효성 검사
    - 1개의 숫자 입력
    - 당첨 번호와 중복 불가, 1~45 범위의 숫자만 허용

- [ ] 당첨 결과 계산
    - 사용자가 구매한 각 로또의 당첨 번호 일치 개수 계산
    - 5개 일치, 보너스 번호 일치 여부 판단
    - 당첨 조건에 따른 등수 및 상금 계산

- [ ] 당첨 내역 및 수익률 출력
    - 각 등수별 당첨 개수 출력
    - 수익률 = (총 당첨금 / 총 구입금액) × 100
    - 소수점 둘째 자리에서 반올림하여 %로 표시

- [ ] 예외 처리 규칙
    - 모든 예외는 `IllegalArgumentException`을 사용
    - 메시지는 반드시 `[ERROR]`로 시작
    - 프로그램 종료 시 `System.exit()` 사용 금지
